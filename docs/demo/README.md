# Demo evidence

Current decision-desk screenshots are generated by `pnpm test:e2e` from
RECORDED fixtures: `decision-desk.png`, `decision-mobile.png`, and
`decision-policy-stop.png`. They show
analysis and replay with no transaction. See [the script](../demo-script.md)
and [the exposure instrument design](../design.md). The current interface uses
deep pine, graphite, platinum and citron, authored issuer sleeves, a normalized
price ruler, an expandable ledger and a separate research verdict.

`baseline-desktop.png` and `baseline-mobile.png` capture the prior deployed
editorial desk before the campaign. `instrument-home-{width}.png` covers
360/390/768/1024/1440 px. Every supporting route has 390 and 1440 px captures;
additional `*-result`, `*-active` and receipt-detail captures show populated
workflows. These are actual local browser results using recorded evidence,
not design mockups or proof of execution.

`browser-measurements.json` reports observed transfer bytes, layout-shift sums
and inspection roundtrip timing. Timing includes Playwright dispatch/assertion
overhead, not field INP. Only the first navigation is cold; later resource sizes
benefit from cache. `color-contrast.json` records sRGB contrast for the primary
text/surface combinations. This is a palette audit, not a full WCAG certification.
