# Bundled typography

Source Sans 3 and Source Serif 4 are self-hosted so the workspace and judge demo
do not need a font CDN. Their SIL Open Font Licenses are included alongside the
variable WOFF2 files. WOFF2 files were losslessly compressed from the upstream
TTFs with fontTools; font outlines and naming were not changed.

- https://github.com/google/fonts/tree/main/ofl/sourcesans3
- https://github.com/google/fonts/tree/main/ofl/sourceserif4

Source Sans 3 handles interface text and tabular figures. Source Serif 4 is used
for editorial headings and the decision record.
